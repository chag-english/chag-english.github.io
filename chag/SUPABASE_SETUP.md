# راه‌اندازی بک‌اند مشترک CHAG

1. یک پروژه مستقل برای CHAG در Supabase بسازید.
2. فایل `sql/supabase-schema.sql` را در SQL Editor اجرا کنید.
3. در Authentication، روش ورود موردنظر را فعال کنید.
4. حساب مدیر را ابتدا در Auth بسازید؛ سپس از SQL Editor نقش همان حساب را مدیر کنید:

```sql
update public.profiles
set role = 'admin'
where id = 'UUID_OF_TRUSTED_ADMIN';
```

5. فقط `Project URL` و کلید عمومی `anon`/`publishable` برای اتصال فرانت‌اند لازم است. کلید `service_role` را هرگز در فایل‌های سایت قرار ندهید.
6. پیش از انتشار عمومی، اتصال Auth، خواندن/نوشتن جدول‌ها، کانال realtime چت و عملیات مدیریتی را با حساب‌های جداگانه دانشجو/استاد/مدیر آزمایش کنید.

**وضعیت فعلی ZIP:** صفحات مدیریت و چت و برنامه تکراری در حالت نمایشی و مبتنی بر `localStorage` هستند. فایل SQL ساختار بک‌اند و سیاست‌های پایه RLS را آماده می‌کند، اما تا زمانی که پروژه Supabase CHAG به فرانت‌اند متصل و تست نشود، داده‌ها بین دستگاه‌ها همگام نمی‌شوند و پنل مدیریت برای انتشار عمومی امن/فعال محسوب نمی‌شود.
